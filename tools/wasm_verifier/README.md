# WebAssembly parity verifier

`src/pure.rs` is the shared `no_std` integer math module used by the UEFI scalar MLP, causal-attention, and SiLU paths and by this Wasm crate. The browser runner checks exact outputs for two MLP modes and two recurrent attention frames; no JavaScript inference arithmetic or floating-point kernels are involved.

## Build and run

```powershell
.\tools\wasm_verifier\build.ps1
node tools/wasm_verifier/serve.js
```

Open `http://localhost:8000/` and select **Run parity checks**. The generated `wasm_verifier.wasm` is loaded directly by the browser with the standard WebAssembly API. Rust parity tests can be run using:

```powershell
cargo +nightly test --manifest-path tools/wasm_verifier/Cargo.toml --target x86_64-pc-windows-msvc --release
```

All tested code is fixed-point/integer-only. The SiLU lookup is generated by the exact same const integer formula as the UEFI core, and causal state and outputs are checked at each frame.
